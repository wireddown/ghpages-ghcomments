# GitHub Comments for your GitHub Pages

With [**ghpages-ghcomments**](https://wireddown.github.io/ghpages-ghcomments), your Jekyll site can use GitHub to provide reader comments.

Set up is straightforward, and everything has been automated to hook into your git workflow.

[Read more](https://wireddown.github.io/ghpages-ghcomments/about)
